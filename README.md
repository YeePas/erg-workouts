# Erg Workouts · sportschool

Website voor sportscholen die de Erg Workouts-app gebruiken: plan losse trainingen en
programma's van meerdere weken (ook uit sjablonen) en bekijk het leaderboard.
Leden gebruiken de iOS-app; beide werken met dezelfde Supabase-database.

Inloggen met het sportschoolaccount. Statische site (HTML/JS), geen build-stap.
